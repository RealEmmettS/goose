TT;DR: Publish a narrow immutable v1.3.2 so the documented Windows bootstrap works inside the Codex app terminal, then install the official bytes on the Alienware and complete the updater/app-runtime proof originally targeted at v1.3.1.

## Why

v1.3.1 is a valid immutable release and its candidate, same-SHA main, atomic publication, all-eight
fresh-public-byte, and production-site gates passed. The first physical install attempt then failed
before download or UAC because the Codex app terminal intentionally omits both inherited processor
architecture variables. Windows still exposes the authoritative machine architecture, but the
bootstrap did not consult it. The v1.2.6 installation remained byte-for-byte unchanged.

## Plan

Resolve architecture from the existing WOW/process signals first, then the Windows machine-scoped
signal, then .NET's OS architecture. Keep x64/ARM64 artifact choice, exact-tag size/SHA-256 pinning,
Global-MSI ownership, UAC, immutable slots, and the v1.3.0 detached app runtime unchanged. Freeze one
candidate SHA, repeat the complete release matrix, verify public/site bytes, and run the unmodified
versionless command from the same scrubbed Codex terminal before updater and lifecycle qualification.

## Impact

The public Windows command no longer depends on optional environment inherited from its hosting app.
Risks are selecting the wrong architecture or weakening bootstrap verification; the ordered native
signals and unchanged exact-artifact pinning keep those boundaries explicit. v1.3.1 stays immutable.

## Acceptance

One exact v1.3.2 commit passes local, candidate, same-SHA main, atomic publication, and all eight
fresh-public-byte gates. The production page advances to the exact release. From the Codex terminal
with processor variables absent, the documented public command installs v1.3.2 and the Alienware
proves receipt/registration/PATH/public-byte/launcher identity, clean one-object updater JSON, one
detached hidden runtime across duplicate starts, graceful stop, and no staging or duplicate residue.
