## Impact
Intended: macOS users see the correct goose, receive a stable Accessibility identity, can install through a no-sudo DMG, launch the existing configuration TUI or request animated Quit from a visible menu-bar item, and get an Apple-notarized primary download. The macOS runtime should stop accumulating autoreleased objects and meet the recorded CPU/RSS envelope. Every platform should enter/leave through real exposed edges, preserve natural monitor seams, and share the hidden-only wrap plus safely gated user-close character reaction.

Risks: pixel-format changes can swap channels or alpha; AppKit object reuse can display stale frames; edge routing can relocate a still-visible pose or mistake a real monitor seam for an exposed edge; close provenance can turn program cleanup into retaliation; lifecycle changes can overwrite foreign files; signing order can invalidate nested code; release workflow changes can partially publish; website promotion can point to an absent or untrusted artifact. Every risk is gated by test-first contracts and candidate/fresh-download verification. Terminal windows remain absolutely excluded from mischief.

The macOS menu-bar bridge must retain its AppKit target for the status item's lifetime, remain main-thread-only, launch configuration without creating an unvalidated settings path, and route Quit through engine-owned graceful shutdown rather than `terminate:` or `exit`.
