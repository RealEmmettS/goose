## Why

The M16 implementation is in-tree and cross-target checks pass from Windows, but macOS-specific proof cannot be produced on a Windows host. This task owns the host evidence required before claiming full macOS backend readiness beyond implementation closure.

## Plan

Use `script/smoke_m16_macos_accessibility.sh` and ADR 0022's managed-app flow rather than a
pre-granted-only shortcut. Build, sign, notarize, and install one exact candidate; record its full
commit and executable digest once, and do not rebuild or replace it anywhere in the sequence.
Native prompt/no-prompt observations require the awake operator. The script's reset and cleanup
flags are explicit and scoped only to Honk300.

Resolution steps:

1. With explicit reset opt-ins, start the exact managed candidate denied. Confirm one native
   consent request and Settings handoff, owner-only marker creation, calm safe-edge wait, truthful
   denied status, working status/reload/honk/stop, and `BUSY` for prank actions.
2. Stop and relaunch the same denied candidate. Recheck its digest and marker identity, then
   confirm neither consent UI nor Settings reopens.
3. Grant Accessibility while that same process is running. Record the transition time,
   same-process FirstUX resume, supported Accessibility/cursor/window status, ordinary-window
   positive, collect/nab behavior, and protected-terminal negatives.
4. Revoke Accessibility while that same process is running. Record the transition time, denied
   status, cancelled permission-bound work, return to the safe wait, no new prompt, and working
   status/reload/honk/stop.
5. Record the one-display hardware waiver without claiming live multi-monitor/hot-plug, then use
   the separate explicit cleanup opt-in to purge the managed test install and reset only
   Honk300's marker/Accessibility record where macOS permits.
6. Append the digest, transcripts, observations, transition times, and cleanup result to
   `docs/readiness/m16-m18-readiness.md`. Close this task only after every verification item is
   passed or explicitly waived with a reason.
