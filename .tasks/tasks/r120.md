## Impact
Intended: users receive the synchronous same-origin updater through signed/notarized Mac artifacts, all Windows installer families and architectures, Debian packages, and shell paths while stable public names keep resolving to exact immutable bytes.

Risks: a failed candidate must not advance main or create a tag. A failed publication must be fixed forward with a new version if immutable public bytes escaped. Branch cleanup must not discard unique unmerged source; the stale side worktree and archive branch are audited before removal.
