# v1.0.2 macOS production patch — shared goose menu icon and exact release

## Status

Active. Owner: codex. Started 2026-07-17.

## Objective

Ship a forward patch from the immutable v1.0.1 baseline that gives the running macOS app a real
goose menu-bar mark, keeps the existing Configure and graceful-Quit semantics, closes the
remaining physical-Mac production checks available on this host, and republishes the complete
cross-platform release matrix through the repository's atomic candidate/tag workflow.

Windows and Linux behavior must remain build- and release-compatible. Their future tray surfaces
will reuse the same tracked icon and control contract, but they are not implemented or claimed by
this task.

## Acceptance

1. `Assets/UI/honk300-status-goose.svg` remains the canonical monochrome source with Quiver
   provenance; AppKit consumes a deterministic 36×36 transparent PNG as an 18-point template.
2. The macOS status item is image-only when the sealed resource decodes, explicitly exposes
   **Honk300 controls** to accessibility APIs, retains its image and action target, and falls back
   to the existing **Honk** text without preventing launch if a development bundle lacks the
   resource.
3. Configure opens the bundled launcher and the one authoritative terminal TUI. Quit records the
   same engine-owned graceful-stop intent as CLI/TUI stop, waits for a fully hidden pose and final
   clear, then releases the singleton. Permission denial does not hide the control surface.
4. Packaging fails closed unless SVG and PNG resources are present before signing and survive the
   staged app, final extracted app ZIP, initial DMG mount, and final notarized/stapled DMG remount.
5. A physical-Mac run proves the icon and accessible menu, Configure/TUI restoration, animated
   Quit/immediate restart, light/dark template behavior where this host permits, and process-
   specific performance. One-display and absent-software limits remain explicit rather than
   upgraded into claims.
6. Candidate mode, exact-SHA default-branch CI, immutable `v1.0.2` tag publication, post-release
   smoke, fresh artifact trust/hash/install/update checks, and the website's stable-latest DMG path
   all pass before closure.
7. ADR 0028, readiness evidence, README, `AGENTS.md`, `CLAUDE.md`, `CODEX_PROJECT.md`, both
   changelogs, the task board, and the Alienware verification handoff agree on what shipped and
   what remains deferred.
