TT;DR: Publish the idempotent Windows update-discovery repair as immutable v1.3.1, verify every supported platform from one exact SHA, then install the official release on the Alienware and prove both updating and the detached app runtime.

## Why

Public v1.2.6 reproduced `PermissionDenied` before download from a normal administrator terminal.
The same pre-download code is present in public v1.3.0: compatible PowerShell/Global-MSI ownership
has no conflict, but cleanup discovery still replaces the unchanged receipt under Program Files.
Because the failure precedes download and elevation, neither published binary can self-repair.

## Plan

Release a patch from the reviewed idempotent receipt-state fix. Preserve the proven origin,
immutable Windows slots, existing UAC installer boundary, conflicting-owner journal, exact artifact
checks, and v1.3.0 controller to app launcher to hidden runtime contract. Freeze one candidate SHA,
pass all platform producers and consumers, fast-forward it unchanged to main, wait for ordinary CI,
publish a new immutable tag, and verify all public bytes plus the production site. Finally cross the
broken installed updater with the official versionless PowerShell bootstrap and prove subsequent
`goose update --json` succeeds normally.

## Impact

Intended: ordinary Windows terminals can check for updates without writing protected state, and UAC
appears only when verified installation work requires it. Risks include weakening owner cleanup,
publishing a platform-incomplete release, installing non-public bytes, or regressing the new detached
app launcher. Older tags and assets remain untouched.

## Acceptance

One exact v1.3.1 commit passes local, candidate, same-SHA main, atomic publication, and eight-lane
fresh-public-byte gates. Exact-tag/latest manifests and versionless installers agree. The Alienware
ends on official v1.3.1 with authoritative PowerShell ownership, identical public aliases, verified
app-launcher identity, clean update JSON from an unelevated terminal, one detached hidden runtime,
and no staging or duplicate residue.
