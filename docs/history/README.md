# Historical project instructions

`AGENTS-before-refinement.md` and `CLAUDE-before-refinement.md` preserve the exact instruction
files from before the approved refinement cleanup, including the detailed release chronology.
Current operating guidance is maintained in the repository-root `AGENTS.md`, referenced by
`CLAUDE.md`. Accepted architectural history remains under `docs/adr/` and qualification
reports under `docs/readiness/`. Historical instructions do not override later accepted ADRs.
