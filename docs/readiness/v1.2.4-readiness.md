## Intent

v1.2.4 is the immutable fix-forward for the unpublished v1.2.3 tag. It carries the complete
command-first managed-installation change and adds one narrow hosted Windows qualification
boundary. The exception applies only when Honk300's exact tray owner exists, the fixed-GUID
rectangle remains unavailable for the bounded window, and an independent stock-icon fixed-GUID
registration/recovery probe also fails. Ordinary Windows CI remains strict and unwaived, while
the hosted exception still runs the real native tray menu, graceful/forced lifecycle, compositor,
PE, and artifact-identity proof.
