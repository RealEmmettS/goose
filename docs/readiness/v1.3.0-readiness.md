# honk300 v1.3.0 Release Readiness

Date opened: 2026-07-19

Target: stable/latest `v1.3.0`

Release task: `#wstart`

Architecture decision: ADR 0036

## Intent

v1.3.0 makes a Windows terminal a bounded start controller instead of the owner of the running
goose. Every public start spelling resolves the branded exact-sibling `honk300-app.exe`, forwards
the complete start option vector, waits for local IPC readiness, and returns. The transient GUI
launcher starts the hidden console-free `honk300.exe` runtime, which retains the authoritative
singleton, overlay, IPC server, and notification-area item after the originating terminal closes.

The release preserves the existing CLI grammar, TUI, config schema, IPC protocol, tray actions,
installer receipt schema, and update provenance. It also gives the user-pinnable app launcher a
binary-specific multi-resolution icon derived from the canonical goose status artwork.
