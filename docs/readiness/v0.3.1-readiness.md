## Release rule

Do not tag or publish until every locally applicable gate below is green and the pushed commit's
hosted platform jobs are green. The stable release must be assembled from the tag SHA in one
draft, verified remotely, and published once. Published releases are immutable; a correction is a
new patch version.

## Host evidence and limits

The Windows workstation can prove local Rust behavior, Windows execution, static cross-platform
contracts, package plans, and web behavior. GitHub-hosted macOS/Linux jobs are authoritative for
native APIs and packaging. Pre-granted Accessibility upgrade evidence remains tracked by `#m16r`
but is not a v0.3.1 blocker. Neither release nor site may promise Accessibility-grant persistence.
