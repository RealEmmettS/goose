# honk300 v1.2.0 Release Readiness

Date opened: 2026-07-18

Target: stable/latest `v1.2.0`

Release task: `#r120` (needs updater implementation `#u31`)

Architecture decisions: ADR 0031, ADR 0032, and ADR 0033

## Intent

v1.2.0 is the provenance-preserving self-update feature release after immutable public v1.1.0.
It adds protected v2 installation identity, synchronous same-origin updates, immutable Windows and
shell-managed Linux release slots, transactional latest-intent takeover, DMG-origin signed app-ZIP
updates, and exact one-object JSON results without changing public unversioned artifact names. It
also closes the Windows note/session-restoration regression, bounds collected props per monitor,
separates graceful and force-stop behavior, makes login start a receipt-owned cross-platform
config preference, removes local full-screen calibration, and gives Windows shortcuts/login
startup a windowless native launch path without changing intentional CLI behavior.
