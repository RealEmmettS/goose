# Honk300 v1.9.0 release readiness

Opened 2026-09-08 for the separately qualified GNOME follow-on, task #rgn and
ADR 0048. Publication follows Hyprland. The candidate adds an explicitly installed
Shell companion for window, fullscreen and actual user-drag observations, backed
by Rust ownership and Native SDK consent controls. It keeps the compatible
XWayland overlay and independent owned-prop positioning. Foreign-window movement,
pointer access and DND remain unavailable.

## Native evidence

[Run 34226098889](https://github.com/RealEmmettS/goose/actions/runs/34226098889)
qualifies the actual GNOME Shell 46.0 and 48.7 interface on native x64 and ARM64:
extension discovery and enable/disable, exact window identity, fullscreen,
Mutter's actual user-grab signals and a complete visible goose outside overview.
The private fixture's window movement/focus methods do not ship in the companion.

[Run 34237848251](https://github.com/RealEmmettS/goose/actions/runs/34237848251)
passes the initial complete production runtime and native-settings lifecycle on
both x64 Shell versions, including actual ordinary/terminal drags, fullscreen
manners, independent settings drafts, live revocation and graceful/crash recovery.
This does not complete the later held-ride interruption and owned-prop gates.

[Run 34243427852](https://github.com/RealEmmettS/goose/actions/runs/34243427852)
passes the complete production runtime/settings and both owned-prop suites on
GNOME 46.0 and 48.7, each on native x64 and ARM64. The provider now omits destroyed
and empty actors during creation/remapping while Rust still rejects invalid
reported geometry. Actual held-input cancellation, extension loss, explicit
reconnection, saved drafts, independent process lifetimes, rendered note text,
uncropped images, capacity, native close, malformed input, EOF, failed helpers
and graceful/crash recovery all pass.

All four native settings/goose captures, all four delivered-note captures and all
four complete-image/capacity captures were inspected. The final settings layout
adds space inside the scrolling content so its scrollbar cannot cover the end
of a wrapped line; the final-source native gates repeat that visual check.

Versioned Windows-host formatting, strict workspace clippy, Rust tests, release
build and 137 Python tests passed. The separate versioned Native SDK tests, check
and production build passed; final-source architecture builds remain required.

Run 34252264898 repeats all four desktop suites and twelve inspected captures
after final scrollbar/input-fixture corrections. Subsequent PR review confirms
four additional defects: omitted embedded source files, blind XWayland pointer
input, transient actors counted before filtering, and periodic consent reads on
the runtime loop. Their correction includes real Cargo selection, production
JavaScript window-bound/cancellation checks and the retained worker's revocation
regression. Full native and publication gates must repeat on the corrected source;
the earlier desktop passes do not qualify those later changes.
