# Goose v1.11.5 readiness

## Reproduction and recovery

The Xcode 27 failure was reproduced with the previous signed release. The first repair and its Linux and Windows qualifications are recorded in [v1.11.4 readiness](v1.11.4-readiness.md).

During public qualification, typing an installed Mac command reported an unknown installer. Running the same signed binary directly from the app recognized the correct receipt. This occurred with the public v1.11.3 and v1.11.4 bytes in the real runner account and in an isolated home. The follow-up uses the kernel’s path for the running executable when checking ownership and finding the settings app. [Public diagnostic run](https://github.com/RealEmmettS/goose/actions/runs/45513884012) · [ADR 0060](../adr/0060-macos-command-image-identity.md)

For an affected older Mac, rerun the installer from the website or rerun the official Terminal install command. After that repair, all three command names can find and update the installation.

## Published downloads and Linux package handoff

All 47 files from the exact tag matched the corresponding latest downloads, GitHub asset digests and stated sizes. Rebuilding the manifest from the downloaded files reproduced the published 22 payload entries. Every checksum sidecar and the combined checksum file matched. Both earlier releases retained their original 47 filenames, sizes and digests.

In a disposable Ubuntu guest an ordinary account installed the published v1.11.4 shell package, then opened the published v1.11.5 Debian package through PackageKit. All three command names reached the new system package. The original configuration bytes, personal note and disabled login startup survived. Removing the package also removed the owned forwarding aliases.

The first guest attempt inherited WSLg’s shared runtime directory from a different account. The old installer correctly refused the foreign-owned runtime before installation. The successful test gave the account its own standard runtime directory. Neither the installer nor the published package changed between attempts.
