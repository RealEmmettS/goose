# honk300 v1.2.6 Release Readiness

Date opened: 2026-07-18

Target: stable/latest `v1.2.6`

Release task: `#cli123`

Architecture decisions: ADRs 0031 and 0034–0035

## Intent

v1.2.6 is the immutable Windows compatibility fix-forward after both public v1.2.5 Windows
lanes proved that supported system Windows PowerShell can lack the optional `Get-FileHash`
cmdlet. The public bootstrap had already downloaded and same-stream-verified exact MSI and
lifecycle bytes, acquired its lease, and completed the MSI before that later launcher-receipt
hash failed. Both bootstrap and CLI coordinator now use direct .NET file streams and SHA-256 for
every remaining hash. Regular-file, reparse-point, size, digest, lifecycle, and final receipt
verification remain fail closed.
