Decision record: ADR 0029

## Scope

v1.0.3 is a forward patch from immutable public v1.0.2. It contains only findings reproduced by
the Alienware verification: native Windows updater invocation and receipt identity, coexisting
Global/Corporate lifecycle ownership, deferred-parent handling, Corporate forced-failure retry,
and conservative Codex/VS Code terminal protection on Windows and Linux. It does not implement or
claim a Windows or Linux tray; that work remains separately ordered for v1.1.0.

The complete release matrix still builds and qualifies Windows, macOS, Linux, Debian, and signed/
notarized/stapled Mac artifacts from one exact SHA. Published v1.0.0, v1.0.1, and v1.0.2 tags and
assets remain untouched.
