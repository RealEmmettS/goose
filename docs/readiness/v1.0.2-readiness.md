## Scope

v1.0.2 is a forward patch from the immutable public v1.0.1 release. It replaces the macOS
menu-bar text with the shared goose template icon, hardens its bundle/resource/accessibility
contract, and records the exact Configure/TUI and graceful-Quit behavior future Windows/Linux
tray work must reproduce. It does not implement or claim a Windows or Linux tray.

The complete release matrix still builds Windows, macOS, and Linux artifacts. Ordinary CLI
updates remain rolling-latest and platform/provenance isolated; the DMG remains an immutable
per-tag graphical installer produced afresh on GitHub's macOS runner for every general release.

## Cross-platform and next-machine boundary

- The shared icon/Configure/Quit behavior is the design input for future Windows and Linux trays;
  v1.0.2 does not add those implementations.
- Hosted release gates must still rebuild and verify every Windows/Linux artifact and installer;
  no macOS-only change may weaken their compilation, lifecycle, updater, or compositor contracts.
- Both Windows targets pass a complete workspace cross-check from this Mac. All four Linux targets
  pass platform-crate cross-checks; a complete Linux root-binary check requires the native ALSA
  sysroot intentionally supplied by hosted Linux jobs and is therefore retained for candidate
  mode rather than misreported as a source failure.
- A reviewed Windows direct-MSI update can leave an older informational version/tag/commit in a
  PowerShell-bootstrap JSON receipt. Authoritative registry/source markers, exact-path update
  proof, and uninstall ownership do not consume those fields, so this is not a safety or release
  blocker. The Alienware pass should either define those fields as informational or add a guarded
  post-MSI receipt refresh with real Windows tests; v1.0.2 does not add an untested Mac-authored
  Windows mutation.
- `#v1a` and the v1.0.2 Alienware handoff retain real Windows x64 and remaining Linux/hardware
  checks. Findings fix forward in v1.0.3 or newer; published tags are never replaced.
