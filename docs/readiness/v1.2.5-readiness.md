# honk300 v1.2.5 Release Readiness

Date opened: 2026-07-18

Target: stable/latest `v1.2.5`

Release task: `#cli123`

Architecture decisions: ADRs 0034–0035, retaining ADRs 0031–0033

## Intent

v1.2.5 is an immutable verifier-only fix-forward after public v1.2.4 Mac installs succeeded but
the post-release smoke rejected the native app installer's legitimate autostart writer identity,
and after both Windows public-byte jobs preoccupied the exclusive lifecycle lease before invoking
the public PowerShell bootstrap that must acquire it. The Mac verifier continues to require
disabled autostart around a foreign LaunchAgent and accepts only the two exact managed writers:
`honk300-installer` and `honk300-install`. The Windows verifier keeps live-old-slot proof in its
dedicated x64/ARM64 slot test, lets the public bootstrap coordinate its own takeover, and captures
subprocess output. Product payload behavior is unchanged.
