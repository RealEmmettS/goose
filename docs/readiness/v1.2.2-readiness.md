## Intent

v1.2.2 is the immutable test-harness fix-forward for v1.2.1. Public run `29652868306` proved
the v1.2.1 product correction on both Linux architectures: two fresh installs preserved the
foreign XDG file, the runtime launched, X11 rendered, native Wayland rendered on both fractional-
scale outputs, and lifecycle commands passed. The later rollback verifier failed because it
required the bootstrap's compact one-line `autostart` JSON after runtime had legitimately
rewritten the same receipt using pretty formatting.

The fix parses the receipt as JSON and validates schema, stable track, active release, tag, and
the exact disabled/owned autostart object. Product code remains unchanged from v1.2.1. No earlier
tag or asset is moved or replaced.
