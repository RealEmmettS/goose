# honk300 v1.3.2 Release Readiness

Date opened: 2026-07-19

Target: stable/latest `v1.3.2`

Release task: `#r132`

Existing decisions: ADRs 0034 and 0036

## Intent

v1.3.2 makes the public Windows bootstrap independent of processor architecture variables inherited
from the launching terminal. It keeps the existing WOW/process probes, then falls back to the
Windows machine value and .NET OS architecture. Artifact selection, exact-tag size/SHA-256 checks,
Global-MSI/UAC ownership, slots, receipts, aliases, and detached app runtime do not change.
