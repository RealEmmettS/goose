# honk300 v1.2.1 Release Readiness

Date opened: 2026-07-18

Target: stable/latest `v1.2.1`

Release task: `#r120` (needs updater implementation `#u31`)

Architecture decisions: ADR 0031, ADR 0032, and ADR 0033

## Intent

v1.2.1 is the immutable fix-forward for v1.2.0's public Linux shell-managed startup failure.
v1.2.0's candidate, same-SHA main, atomic publication, Windows x64/ARM64, Debian amd64/arm64,
and managed Mac public-byte gates passed. Both Linux shell jobs then reproduced one symmetric
defect: the bootstrap preserved a foreign XDG autostart entry but recorded autostart as enabled
solely because the path existed. Runtime ownership validation correctly refused the foreign file,
which made startup fail before compositor qualification.

The correction records autostart as enabled only for a regular marker-owned LaunchAgent or XDG
entry. Foreign files, symlinks, and directories remain untouched and count as Honk300 autostart
being off. Disabling is a no-op for foreign state; enabling still fails closed on the conflict.
No v1.2.0 tag or asset is moved or replaced.
