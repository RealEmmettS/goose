## Intent

v1.3.7 is an immutable fix-forward for the Windows self-update lifecycle archive handoff exposed
by official v1.3.5-to-v1.3.6 acceptance. It changes only the generated PowerShell representation
of a backslash from a quote-adjacent literal to `[char]92`; traversal rejection, verified leases,
install selection, receipts, slots, packages, mud behavior, and every public interface remain
unchanged.
