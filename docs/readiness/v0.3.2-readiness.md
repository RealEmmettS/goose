## Release scope

This patch replaces the placeholder agreement shown by every Windows MSI with one shared,
minimal RTF. The document presents the authoritative PolyForm Noncommercial License first and a
1,800-2,200 word, explicitly non-binding Great Honk Accord second. It also includes the published
installer lifecycle smoke added after v0.3.1. Runtime behavior, configuration, platform backends,
installer ownership, the Inno flows, and third-party asset terms do not change.

Published releases remain immutable. Candidate mode must verify the exact proposed tag and commit
without publication before the tag is created. Release mode must rebuild from that immutable tag,
assemble and verify the complete artifact set in one draft, and publish stable/latest only after
remote names and bytes match.

## Host limits

The Windows workstation can execute the source, RTF, x64 UI, and x64/ARM64 WiX-definition gates.
Its Visual Studio installation lacks the ARM64 CRT libraries, so the local ARM64 Rust link stops
at missing `msvcrt.lib`; the ARM64 definition gate therefore used the verified v0.3.2 x64 binary
as a structural payload. GitHub's Windows runner remains authoritative for the real ARM64 binary,
MSI payload, and administrative extraction. GitHub-hosted jobs are also authoritative for native
macOS/Linux packaging and the complete cross-platform artifact graph. The still-open pre-granted
macOS Accessibility evidence task `#m16r` remains outside this copy-only patch and does not block
release under ADR 0018/0019.
