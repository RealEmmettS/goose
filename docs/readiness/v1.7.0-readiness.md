# Honk300 v1.7.0 release readiness

Opened 2026-09-08 for the independently qualified Sway follow-on, task #rsw and ADR
0046. Publication follows the preceding KDE stage. The candidate adds explicit
read-only Sway window/fullscreen awareness in CLI and Native SDK settings. Window
movement, user-drag observation, pointer access and DND remain unsupported.

## Native evidence

[Run 34212710026](https://github.com/RealEmmettS/goose/actions/runs/34212710026) proves
the native interface and exact fixture-owned six-pixel move on Sway 1.9/1.10.1,
each on native x64/ARM64. The public protocol's missing active-drag state prevents
using that movement operation in production; normal native prop placement remains.

[Run 34215421415](https://github.com/RealEmmettS/goose/actions/runs/34215421415) qualifies
the production read-only Rust transport and decoder on all four desktops. A same-user
impostor socket is refused before receiving any query. Bounds cover version, tree
size/depth, output/window counts, exact peer ownership and a single exchange deadline.

[Run 34218062301](https://github.com/RealEmmettS/goose/actions/runs/34218062301), source
`46f9d1e7046c1012b5e810b04f67b111b17f656b`, passes the complete actual runtime and
native settings lifecycle on all four desktops. Artifacts contain native consent,
cancel/remove, engine fullscreen manners, live option changes, retained drafts, exact
worker cleanup, external revocation, replaced sockets, deliberate reconnection,
graceful/crash restart and preserved unrelated configuration. Real split-container
fullscreen and powered-off output states exercise the production decoder directly.

The first runtime fixture omitted enabling the private accessibility bus and failed
before locating native settings controls. The corrected fixture uses the same
service activation as existing KDE and SDK checks. No accessibility oracle was
relaxed. Captured split/fullscreen and missing-output regressions failed before the
decoder correction. Native fragmented, oversized, mismatched and disconnected socket
tests exercise the actual exchange with a bounded total deadline.
