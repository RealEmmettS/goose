# honk300 v1.3.4 Release Readiness

Date opened: 2026-07-21

Target: stable/latest `v1.3.4`

Release task: `#r134`

Decision: ADR 0038

## Intent

v1.3.4 adds an always-visible **Update Honk300…** action to Windows, macOS, and compatible
Linux native control surfaces. A click opens a terminal and runs the existing verified updater
without manual typing, relaunches the receipt-owned app after activation, recovers the retained
authoritative app after a stopped-runtime failure, and leaves one unambiguous result screen until
the user closes it. Public updater output and every installation-origin rule remain unchanged.
