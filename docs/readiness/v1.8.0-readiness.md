# Honk300 v1.8.0 release readiness

Opened 2026-09-08 for the independently qualified Hyprland follow-on, task #rhy
and ADR 0047. Publication follows Sway. The candidate adds explicit read-only
Hyprland window/fullscreen observations to the CLI and Native SDK settings.
Movement, user-drag observations, pointer access and DND remain unavailable.

proves the actual interface on Hyprland 0.53.3 and 0.55.2, each on native x64
and ARM64. The public interface has no authoritative current user-drag state;
the fixture's bounded movement proof does not authorize production movement.

The native fixture uses the retained production observer's fresh fullscreen

## Required publication gates

- [x] Independently qualify the native interface and production observation boundary.
- [x] Exercise actual Rust/native GUI lifecycle on all four Hyprland desktops.
- [x] Inspect rendered native settings and prove note/image delivery and failure cleanup on those desktops.
- [x] Pass versioned local formatting, strict lint, Rust/Python tests and release build.
- [x] Pass separate Native SDK test, check and real build.
- [ ] Pass final-source PR gates and all native architecture/settings lanes.
- [ ] Pass the complete candidate with all eight archives, native installers, Debian packages and signed/notarized/stapled Mac artifacts.
- [ ] Merge unchanged source, pass main gates and publish a new immutable release after Sway.
- [ ] Verify fresh public artifacts on every architecture and independently audit every manifest identity.
- [ ] Update and verify website guidance against the public bytes.

Hyprland is a required same-source candidate and publication dependency, alongside
the separate KDE/Sway and settings/platform/package gates. These private automated
desktops do not establish physical Pi performance, Mac permission acceptance or
Windows elevation acceptance. No other compositor inherits the evidence.
