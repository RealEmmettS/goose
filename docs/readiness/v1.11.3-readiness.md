`installed-verification-routes.json` and `controller-diagnostic-observation.json`.
Other direct probes obtain input-idle success, so the underlying scheduling condition
remains unknown. The correction addresses the demonstrated mismatch between responsiveness
and the startup predicate; it does not claim a scrolling regression or unconditional

ignored by ordinary discovery and invoked by those tests. The busy GUI-subsystem fixture must
first produce `WaitForInputIdle=258`, then succeed through the new exact-child response check.

their failure outcomes and ordinary prompt cleanup. Independent review caught and removed an

build pass. Native settings passes 18 SDK tests, 15 accessibility tests, strict validation and
