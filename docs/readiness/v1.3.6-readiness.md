Date opened: 2026-07-23

Decision: ADR 0039 calmer default mud cadence

## Intent

v1.3.6 makes mud an occasional accent. Automatic puddle hops move from 70–160 to 180–300
seconds apart and track new mud for 10–30 instead of 30–90 seconds. Fresh/direct mud defaults to
10 instead of 15 seconds while existing explicit configuration remains authoritative. Puddle
travel, footprint fade, rendering, sound, manners, configuration schema/surface, platform,
packaging, updater, and lifecycle behavior remain unchanged.
