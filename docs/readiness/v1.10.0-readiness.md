# Honk300 v1.10.0 release readiness

Opened 2026-09-08 for audit R05, task #prs and ADR 0049. This release follows
the independently qualified compositor releases. It adds Mac fullscreen manners
through existing Accessibility permission and reports fullscreen and DND
observations separately in the CLI, TUI and Native SDK settings.

Mac DND remains unsupported: the private Focus authorization experiment has not
qualified an app-specific grant and actual on/off signal. Linux fullscreen
comes from the explicitly enabled desktop adapter; its DND capability remains
unsupported. Windows retains its notification-availability mapping and can
recover its capability after a successful poll following failure.
