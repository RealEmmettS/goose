# honk300 v1.3.1 Release Readiness

Date opened: 2026-07-19

Target: stable/latest `v1.3.1`

Release task: `#r131`

Existing decisions: ADRs 0031, 0034, and 0036

## Intent

v1.3.1 repairs Windows update discovery for ordinary unelevated terminals. A compatible
PowerShell/Global-MSI installation whose protected receipt already records the correct cleanup
state is now a read-only discovery path; actual state transitions retain their atomic protected
write. The patch does not change provenance, installer selection, immutable slot activation,
conflicting-owner retirement, public command grammar, or the detached Windows app runtime.
