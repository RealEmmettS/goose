# honk300 v1.3.3 Release Readiness

Date opened: 2026-07-19

Target: stable/latest `v1.3.3`

Release task: `#r133`

Decision: ADR 0037

## Intent

v1.3.3 lets the transient Windows app launcher break its exact hidden runtime out of a
breakaway-permitted integrated-terminal job. It keeps the original windowless flags as the only
access-denied fallback and does not change renderer, runtime, installer, updater, or ownership
behavior.
