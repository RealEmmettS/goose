Target: stable/latest `v1.1.0`

Decision record: ADR 0030

## Scope

v1.1.0 is the tray-parity feature release after immutable public v1.0.3. It adds native Windows
notification-area and Linux StatusNotifier controls while preserving macOS behavior, the one
terminal TUI, the same local IPC boundary, and engine-owned graceful shutdown. It does not add a
native preferences window, global quit key, GTK/AppIndicator dependency, or new Linux compositor
capability claim.

The complete release matrix still builds and qualifies Windows, macOS, Linux, Debian, and signed/
notarized/stapled Mac artifacts from one exact SHA. Published earlier tags and assets remain
untouched.
