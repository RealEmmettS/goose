# honk300 v1.0.0 Release Readiness

Date opened: 2026-07-12
Target: stable/latest `v1.0.0`
Branch: `codex/v1.0.0`
Board: `#m20q`
Decision records: ADR 0018 (atomic publication), ADR 0019 (stabilization), ADR 0020
(Developer ID macOS distribution), ADR 0022 (macOS Accessibility first-run onboarding), ADR 0023
(rolling latest and Debian lifecycle), ADR 0024 (macOS menu-bar control), ADR 0025 (first stable
major release plus post-release hardware-verification boundary), and ADR 0026 (strict hosted
Windows ARM64 compositor-evidence boundary)

## Release rule

Do not create the tag until every pre-tag release blocker through the candidate run is complete on
one exact commit. Candidate mode must prove the complete artifact graph before the default branch
is advanced. Publication, fresh-download checks, and website rollout are necessarily post-tag
closure gates; do not promote the website DMG until those checkboxes also pass. Missing signing/
notarization credentials, failed performance, or incomplete Accessibility evidence fail closed.
