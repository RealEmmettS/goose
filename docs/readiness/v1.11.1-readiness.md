# Goose v1.11.1 readiness

## Scope

The settings and tray follow-up in [ADR 0054](../adr/0054-settings-navigation-and-shared-artwork.md)
and task #g12: visible selected tabs, short smooth wheel scrolling, Linux-only Wayland
controls, and each platform's existing application artwork in its tray or menu.
The approved Windows application badge and Mac/Linux application PNG are unchanged.
The accepted follow-up also includes opt-in seasons and intentional petting (ADR 0055),
bounded Windows bitmap reuse and four-pass performance qualification (ADR 0056).
